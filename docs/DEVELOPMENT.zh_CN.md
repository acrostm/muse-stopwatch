# 架构与真机验收

`build.py` 负责隔离源码准备和 ESP-IDF 构建；`upstream-hashes.json` 将补丁涉及的文件绑定到固定 SDK。`package.py` 核验 Flash 布局，将应用、ELF、配置、分区表及源码指纹保存到本地按内容寻址的产物包。

`sw_core` 实现有界 UTF-8 历史、分行解析、持久 PIN 校验、空闲配对判断及按键时长／取消状态机。输入与录音任务之间用短 FreeRTOS 临界区同步。音频保留在 PSRAM，实际松手且超过两秒才进入上游发送流程。松手时间在事件入队前记录，因此唤醒、预录音和采集尾音不会增加按键时长；溢出或错误直接丢弃，不退回流式发送。

`sw_runtime` 同步配置与历史；`sw_portal` 提供热点页面并将慢操作交给工作任务；`sw_voice` 处理音色发现与有界试听；`sw_tts` 处理服务端流、PCM 与代际取消；`sw_proxy_core` 实现最多八个 SSID 代理配置和 SOCKS5 请求，`sw_proxy` 用版本化 NVS blob 保存、迁移旧全局代理并包装限定域名的 DNS/connect。路由根据实际连接的 SSID 选择，缓存的虚拟目标绑定原 SSID，换网络后拒绝旧目标。网页编辑所选网络的代理，单独改代理不会覆盖已保存 Wi-Fi 密码；`sw_pages` 在 UI 任务维护 LVGL。开发板、麦克风、编解码器、头像、Muse 配对和云会话仍由上游负责。

主机测试通过 ASan/UBSan 执行真实 C 实现，覆盖时长边界、UTF-8／历史边界、分片语音流、取消、与 Python HMAC 对照的签名、分片 SOCKS5 网络、代理配置迁移／隔离／修改、实际网页 JavaScript 网络选择及产物篡改检测。固件任务还会执行 `tools/test_ui.py`，在 ASan/UBSan 下使用 SDK 的真实 LVGL，覆盖当前页初始为空、显式初始化首页、渲染、连续二十次切页、滑动和合并导航请求。仅平台调用使用桩，字体夹具用 Montserrat，因此不能证明实际按键、中文字形和板级外设，这些仍需真机检查。

## 真机检查

- 分别测试短按、约两秒按住、明确较长的录音，仅最后一项应到达 Muse；精确边界需串口计时验证。
- 按住蓝键超过两秒，再按黄键取消，最后松开蓝键，确认无消息到达；重新录制应可正常发送。
- 按住至录音上限而不松手，确认未发送；松手后不能卡在录音状态。
- 检查低内存不会退回实时发送、离线确认录音缓存、重连及队列上限。
- 检查中文字形、各页面、TTS 播放、音色选择试听、重启配置保留、云连接恢复、热点超时、电池休眠唤醒和目标手机热点。
- 分别报告构建、主机测试、真机测试、未验收项；构建失败后不可用旧二进制代替。

## USB 截图

仅为文档截图，在准备后的构建配置中启用 `CONFIG_LV_USE_SNAPSHOT=y` 并重编译。开启上游 USB 截图与 `>sw.docs=1`、`>sw.docs=2`、`>sw.docs=3` 示例设置／状态／历史页。示例模式只修改显示，不更改网络或配对配置，重启退出。`tools/capture.py` 使用原始 USB 文件描述符，不切换 DTR/RTS：

```bash
python3 tools/capture.py /dev/cu.usbmodemXXXX --page 2 --out docs/images/status.png
```

生产默认关闭截图功能。不要将真实设置或对话页用于公开文档；仓库截图来自示例模式，且不包含上游头像素材。
